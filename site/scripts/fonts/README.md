# Font for Chinese social preview cards

`NotoSansSC-Regular.ttf` is used only by the build-time image generator. It is
not included in the public site's font downloads. The resulting PNGs contain
the rendered text and need no fonts on the reader's device.

Source: Fontsource's Noto Sans SC 5.3.1 distribution, file
`noto-sans-sc-chinese-simplified-400-normal.woff2`, obtained from
https://cdn.jsdelivr.net/npm/@fontsource/noto-sans-sc@5.3.1/files/noto-sans-sc-chinese-simplified-400-normal.woff2

The WOFF2 container was decoded to its original TrueType tables using
FontTools. Glyphs and font naming were not edited. This subset contains the
Simplified Chinese and Latin glyphs distributed by Fontsource.

Upstream family: https://fontsource.org/fonts/noto-sans-sc
